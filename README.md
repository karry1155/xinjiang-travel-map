# 新疆 8 日路线动画

一个静态前端页面，用开源地图和逐日动画展示新疆 8 日旅行路线。

## 页面内容

- 逐日播放飞机线和汽车线
- 当前天详情面板
- 夜宿/返程节点标注
- 总览模式和单日聚焦模式
- MapLibre GL JS 地图引擎
- OpenStreetMap 地图底图

## 本地预览

直接打开 `index.html`，或启动一个静态服务后访问页面。
